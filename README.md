# MatchSync

MatchSync is a full-stack Sports Facility Reservation System built with C#. It is designed to streamline facility bookings and manage customer transactions efficiently.

### Features
* **Integrated POS System** Includes Point of Sale functionality for seamless transactions.
* **Guest Booking Model** Simplifies user access and allows quick reservations.
* **Relational Database Schema** Structured using SQL to ensure data integrity and scalable architecture.
* **Robust Backend** Built with scalable backend architecture principles for system reliability.

### Technologies Used
* C#
* SQL
* Backend Controller Endpoints
